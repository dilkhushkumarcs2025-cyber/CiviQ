## What is CiviQ?

CiviQ is a civic-tech platform designed to make public problems more visible, trackable, and transparent.

Instead of treating every complaint as an isolated request, CiviQ converts multiple citizen reports about the same problem into a single **Public Issue**.

Citizens can report problems using:

- 📸 Photos
- 📍 Location
- 📝 Description
- 🗓️ Date & Time
- 📌 Issue Category

Other citizens can then support the same issue, provide additional evidence, and follow its progress.

Authorities can manage these issues through a dedicated dashboard.

The basic idea behind CiviQ is:

```text
Citizen Reports
       ↓
Evidence + Location
       ↓
Duplicate Detection
       ↓
Public Issue Created
       ↓
Multiple Citizens Confirm
       ↓
Authority Assignment
       ↓
Work Progress Tracking
       ↓
Resolution Evidence
       ↓
